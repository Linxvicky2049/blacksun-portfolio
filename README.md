# BLACKSUN — OKAFOR VICTOR SOMTO Portfolio

A custom, original portfolio redesign for OKAFOR VICTOR SOMTO.

## Highlights
- Dark BLACKSUN visual system with neon lime/cyan/pink accents.
- Three.js interactive particle field with pointer response.
- CSS 3D tilt interactions and animated orbit/radar/orb graphics.
- Scroll reveal transitions, marquee, responsive mobile layout and reduced-motion support.
- Project storytelling for Gaming-Africa.com, KageFlow AI, SenseGrid and BizBuySell.
- AI-native engineering section aligned with modern full-stack workflows.
- Uses supplied BLACKSUN artwork and avatar.
- Resume download included.

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.
